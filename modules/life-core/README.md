# 行动与经历核心

从 Aurabot 的「行动与经历核心」面板进入「记忆时间线」，可按聊天筛选，展开权威原文或实际工具结果。私人日记仍在自主生活的日记页。独立使用 DSH 或 WorkBuddy 的会话不进入机器人的经历；由机器人委派的工具调用才关联到对应事件。

`life.sqlite`追加保存任务开始、完成、失败、中断与来源。模型取材视图有界，原始已存记录不会按容量自动裁剪。重启后的在途任务标为中断，不自动重发。主动私聊共用现有speakUp空闲、间隔、每日尝试额度与night睡眠状态；普通聊天不走主动额度。

公开说说和独立私人日记使用不同的群白名单（diary.sourceGroups和ext.autonomy.diarySourceGroups），初始均空。空名单不阻断公开网页/B站等来源。群授权不会扩展普通群聊读取权限；撤权或忘记后，未提交日记重新核验来源，不能通过派生笔记绕过。

「上下文诊断」区分已准备的材料、实际进入请求的来源和模型请求结果。统一记忆块每轮最多 6,000 字符；原生聊天历史、工具结果、人格和系统提示另计。「任务与健康」显示承诺、待补入与存储状态。待补入只把已确认发送的原话和原始时间交给下一轮，不会重发。

纠错保留原话供核对，但撤下过时的派生上下文。忘记也会使相关快照与待补入失效；受控备份有独立的恢复规则。最近最多保留 256 个上下文快照用于诊断，原始聊天及真实行动不受此上限影响。

模块同进程受信任，不是第三方代码沙箱。公开搜索和阅读不会自动获得发帖、私信、安装或任意系统命令权限。宿主接口见 [模块 API](../API.md)。

更新模块市场同名分叉仍可能覆盖本地实现。代码回滚不应恢复旧数据覆盖新经历。
