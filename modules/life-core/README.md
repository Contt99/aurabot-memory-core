# 行动与经历核心

从 Aurabot 的「行动与经历核心」面板进入「记忆时间线」，可按聊天筛选，展开权威原文或实际工具结果。私人日记仍在自主生活的日记页。独立使用 DSH 或 WorkBuddy 的会话不进入机器人的经历；由机器人委派的工具调用才关联到对应事件。

「概览」先显示当前任务、近期经历和需要处理的异常。进「上下文诊断」选择一轮后，可以先看实际进入请求的材料，再展开仅准备或没有采用的内容。

### 给自主生活加一个只读工具

市场模块原有的聊天工具照常使用。适配模块可另行导出 `lifeCapabilities()`，例如：

```js
lifeCapabilities: () => [{
  id: 'current', name: '查询天气', effect: 'read',
  args: { city: '城市名' }, required: ['city'],
  run: async ({ city }, { signal }) => readWeather(city, signal)
}]
```

模块返回明确的 `{ ok, message, ... }`。核心按运行中模块发现它，面板列出完整 ID（如 `weather--current`）。在「授权自主生活的扩展只读工具」填写该 ID 并保存后才允许后台探索调用；停用或移除 ID 后不再调用。该授权不会让结果跨聊天共享，也不能为评论、点赞等开权限。模块仍必须是受信任的代码；接口声明不是沙箱。

自主生活、B 站、RSS 的到期检查由统一时钟调度，保留各模块原时间、配置、执行门禁与手工入口。「任务与健康」列出已登记检查；检查通过不代表做过或已发消息。其他旧后台入口暂不冒称已纳管。自主生活的 B 站浏览只走独立读取；定时互动和手工互动仍受原有设置管理。

`life.sqlite`追加保存任务开始、完成、失败、中断与来源。模型取材视图有界，原始已存记录不会按容量自动裁剪。重启后的在途任务标为中断，不自动重发。主动私聊共用现有speakUp空闲、间隔、每日尝试额度与night睡眠状态；普通聊天不走主动额度。

公开说说和独立私人日记使用不同的群白名单（diary.sourceGroups和ext.autonomy.diarySourceGroups），初始均空。空名单不阻断公开网页/B站等来源。群授权不会扩展普通群聊读取权限；撤权或忘记后，未提交日记重新核验来源，不能通过派生笔记绕过。

「上下文诊断」区分已准备的材料、实际进入请求的来源和模型请求结果。统一记忆块每轮最多 6,000 字符；原生聊天历史、工具结果、人格和系统提示另计。「任务与健康」显示承诺、待补入与存储状态。待补入只把已确认发送的原话和原始时间交给下一轮，不会重发。

接入「图片理解复用」时，同一聊天内已验证的 QQ 图片收发按内容身份合并。记忆快照显示这段连续记录里同图出现几次、收发各几次，最多附一份已有视觉描述。发送确认只证明发过，不能当作看过；没有可验证身份的旧图片占位仍照常显示。

普通追问先接紧邻对话，再参考旧材料。有当前 QQ 原生身份时（宿主提供的群聊直接请求者，或私聊原生附件），在同一聊天查证引用，并把引用对象放在连续记录前；当前身份或引用原文不明确时不猜配。纯文本私聊仍使用宿主本轮带来的原生引用。旧视觉理解只在图片相关回合或本轮有图时作为背景，不抢普通短句的主题。

聊天与主动发言标明贴吧、B站经历的素材渠道。发送前，声称在 QQ 群看到具体内容时须能对应有权限的群消息；声称自己发过某段消息时核对同聊天的原文回执，声称常发则需至少两条不同回执。拦截无依据的这类草稿不修改已有聊天；想法、愿望和真实看帖感想仍可正常发送。

普通 QQ 新回合在正式 `prompt` 钩子中等待精选事实检索，再生成唯一的记忆快照。该快照的 `memoryRecall` 和 `/telemetry` 的 `memory-recall` 条目区分混合检索（`hybrid`）和纯关键词（`lexical`），并记录降级原因。查询失败或超时仍使用关键词；后台同步编排和已运行回合的插话不等待 embedding。实际模型请求和发送前仍复核快照的具体来源。

纠错保留原话供核对，但撤下过时的派生上下文。忘记也会使相关快照与待补入失效；受控备份有独立的恢复规则。最近最多保留 256 个上下文快照用于诊断，原始聊天及真实行动不受此上限影响。

模块同进程受信任，不是第三方代码沙箱。公开搜索和阅读不会自动获得发帖、私信、安装或任意系统命令权限。宿主接口见 [模块 API](../API.md)。

更新模块市场同名分叉仍可能覆盖本地实现。代码回滚不应恢复旧数据覆盖新经历。
