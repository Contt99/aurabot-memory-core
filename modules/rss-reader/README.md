# 自主上网（rss-reader）

配置 RSS / Atom 订阅源后，她会定时读标题和摘要。挑中的条目保存为主人私聊、私人日记可用的素材。

## 它做什么

- 按你设的间隔（默认 2 小时，带 ±20% 抖动）拉取订阅源，支持 RSS 2.0 / Atom / RDF；
- 已读去重（同一件事不会反复喂），单源连续失败自动退避（2 分钟起翻倍，封顶 6 小时）；
- 用「关键词 + 新鲜度」粗筛一遍，只挑达到兴趣门槛的条目，再按每日额度限量；
- 行动核心记录实际读取时间和来源，并保存通过额度筛选的摘要。发布时刻是订阅源提供的信息，不等于读取时间。
- Aurabot 1.2.1 只保存素材，不独立发 QQ。`policy` 和 `pool` 两个旧设置值都保留。

## 怎么用

1. 面板里打开本模块，填订阅源（每行一个 RSS/Atom 地址，`#` 开头是注释）；
2. 设定「多久看一次」「每天最多保存几条素材」「兴趣门槛」；
3. 点「现在看一轮」，在「最近保存的订阅摘要」确认读取结果。

每天上限设为 0 时，仍读取并记录结果，但不保存新素材。

## 会访问哪些网址

读取你填写的订阅地址，不访问条目链接。素材只包含外部订阅摘要，不代表她读过正文。
素材仅供当前主人私聊和私人日记使用；移除订阅后停止取材。

## 数据存放

插件数据目录中的 `rss-state.json` 保存去重、退避和本地来源身份。核心账本保存读取回执和选中摘要，重启后仍能查看。

## 权限

`network`（拉订阅源）、`filesystem`（读写自己的状态文件）、`plugin-config`（读本模块设置）。
