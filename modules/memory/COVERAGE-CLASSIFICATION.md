# 25 个现有模块：只读覆盖分类建议

依据本次 baseline 的 16 个内置与 9 个外置模块入口。以下是接线验收清单，不是“25 个背景任务全部已适配”的结论。最终状态由 root 对实际候选代码及运行状态填写。

| 模块 | 建议分类 | 核心应记录什么 / 真实缺口 |
|---|---|---|
| bili | 背景适配 + 工具观察 | tick/run/checkReplies 及看视频、评论、弹幕、改资料的真实 provider 结果；仅工具 observer 不覆盖刷站定时器 |
| contacts | 工具观察 | 好友/群申请处理与白名单修改；OneBot 入站申请不是已处理的证明 |
| diary | 背景适配 + 工具观察 | 自动 writeDiary/tick、手动 post/remove、公开归档收集分开记录；日记正文不能再当新事实来源 |
| imagegen | 工具观察；面板路径另查 | 工具返回画作与实际发图回执；面板登录/删除不会自然经过 DSH 工具 observer |
| memory | 数据/非外部行动 + 忘记适配 | 主记忆、整理与权限合同保留；本次新增已接受忘记及精确管理删除传播，不把记忆整理宣称为外部行动 |
| mood | 非行动状态 | 心情数值/来源隔离；不把感受或分类推断当做已执行任务 |
| profile | 工具观察 | 查/改自己资料与实际头像发送结果；权限原样保留 |
| purpose | 背景适配 | tick/fire 主动决策与真实 QQ 发送，需共享主人出站闸，不覆盖正常用户应答 |
| qq-api | 工具观察 | 发现接口与实际 OneBot 调用分别记录；接口描述不是执行证据 |
| qq-tools | 工具观察 | 当前聊天读取、发送消息/文件/卡片等实际回执；保留当前观众/白名单权限 |
| qzone-social | 背景适配 + 工具观察 | 自动浏览/回复/点赞与工具动作分开，记录 provider 结果，不把 dryrun 算成功 |
| song | 工具观察；面板路径另查 | 唱歌/点歌完成及发送结果；模型或任务“已排队”不能视为已完成音频 |
| speakup | 背景适配 | 主动发言 tick/propose 进入共享闸，实际 ACK 记录成功；自己的时间窗/次数仍有效 |
| stickers | 工具观察；自动发送另查 | 查询、收藏、编辑、发送区分；自动选图若不走工具，需要真实 sent 观察且保留来源隔离 |
| video | 工具观察；面板路径另查 | 生成/下载/发送的实际完成值；远端排队及失败如实保留 |
| voice | 工具观察/自动回复旁路另查 | 语音生成与发送；普通聊天 TTS 不是 DSH 工具，依赖 sent 或明确输出适配 |
| autonomy | 背景适配 + 私密日记 | 真实受限工具 loop、实际工具结果、本机私密 journal；计划文字不能当行动证据 |
| history-vault | 数据/非行动；来源适配 | 本次显式群只读素材、真实 uid/@/同聊天 reply、确切源存续与忘记墓碑；压缩文本是派生资料 |
| impression-card | 工具观察 + 背景缺口待核 | 工具调分/渲染/发送可观察；proactiveTick 主动微调有独立定时器，本次未替它加背景适配 |
| meme-wiki | 本地查询工具 + 背景缺口待核 | 本地词条查询可观察；定时 syncIfReady/按需 import 并非聊天工具路径，本次未加后台结果适配 |
| moodboard | 展示/非行动 | 显示已有状态；浏览器定时刷新不算 bot 行动。面板 open 是客户端 UI，不当互联网任务完成 |
| night | 非事实状态 + 背景缺口待核 | 睡眠状态可供共享 gate 读取；定时梦生成、手动 dream 是单独模型后台，梦不能当真实外界经历，本次未接其任务结果 |
| qwen-tts | 配置/UI；面板动作缺口待核 | get/set/install 与 test/send 的作用不同；面板试听/发送不经 DSH observer，本次未加此路由背景记录 |
| rss-reader | 背景适配 | 定时 RSS 真正获取条目与主动分享决策分别记录；工具观察不能自动覆盖定时器 |
| tieba-reader | 背景适配 + 工具观察 | search/browse/read 真实结果，tick/run 自动读帖/分享另接；保留只读不发帖回帖 |

“不可用”应由有效运行状态、缺失导出/连接、账号或 provider 错误决定；静态代码有某能力不代表生产已启用。工具观察只能宣称真实经过 observer 的工具调用，背景适配只能宣称已接线并有检查证据的入口。
