# 图片理解复用

同图再次出现时复用已有视觉理解，不统计谁常发，不设置收发专用分支。按聊天保存和读取；GIF首次采样最多5帧。识别输出包含不确定性，低置信度不缓存。

在聊天中要求重新识别，或由模型调用 review_image 可核对最近30分钟的图片；其 forget 动作清除当前聊天缓存。自然语言显式忘记联动清理，持久忘记代次阻止模块重载期间漏通知后复活旧缓存。

复用现有印象卡片 sharp 原生依赖，或宿主 sharp；不在聊天时安装软件。首次理解使用当前聊天配置的模型，超时25秒；同图复用无需再次识图。lossless重编码可按精确像素匹配，有损重压缩不能保证命中，不作模糊合并。

数据位于 modules-data/image-familiar/images.sqlite 和 raw/；管理页面只通过原SSH隧道访问。首次识别失败时保留原聊天输入并明确标注失败，不假装已经记住。


## 0.1.0-local.2：真实视觉观察与精确失效

新识图/明确重看可向核心报告 `visual-interpretation`，保留置信度、不确定性和实际帧数；同图缓存命中不作为新独立事实再次写入。不保存“谁常发”。`image:<chat>:<identity>@<uuid>` 标识一次实际理解；识图观察时间与未知画面事件时间分开。

本地`image_sources`只保存来源身份/作用域/时间/忘记代次，`contextCurrent(ids,{chatId})`同时核对具体来源与核心持久忘记代次。刷新会失效被替代理解；低置信度的纠错不能在下次复用旧的确定描述。

清缓存后按精确image来源ID同步清除核心派生观察；核心scope忘记回调使用不带chatId的nested精确通知，避免递归。联动失败保留本地清理结果并在工具结果/日志或原忘记错误中显示。
