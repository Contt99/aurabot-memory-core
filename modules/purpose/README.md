

## 2026-11-15 本地增量
目的候选和追问接入当前目标获准的真实经历，源ID持久关联；撤权/忘记后丢弃派生目标和在途发送。共享nextFireAt与格式化文字使用同一时间。

status.nextFireAt/nextFireText现在共同表示考虑共享冷却、空闲和安静时段后的最早尝试时间，不是发送承诺；原始共享冷却nextAt和实际作息不改。睡眠、静音或素材不足仍可能阻止该时刻发送。

兼容入口 state().nextFireAt 保留旧共享冷却值；新增 state().earliestAttemptAt。status().cooldownUntil 提供原始冷却值。

## 2026-11-16 主动时间与私聊衔接修复

目的候选与选中证据携带原始来源日期；检索时间不再伪装成事件发生时间。一次性事件分享对完整保留的成功历史去重，真正有新来源可再提；普通未完成事项不套永久禁止。旧素材仍可引出现在的感想，不能说成“刚在群里看到”。发布前检查拦截明确时间冒认，本轮失败且不向QQ补发。

purpose与追问在后台独立会话生成，所以投递标记改为own=false，复用宿主正式的跨会话发言补入机制。对方下一次在同一私聊发来消息时，会收到她实际已说出口的内容；不向其他私聊或群聊复制。补入一次后由普通聊天会话历史保留。未发送成功的草稿不当作说过，心情提醒与回执统计保持原样。

宿主待补入队列仍在内存中（最多5条、每条300字）；在对方回复前重启DSH可能丢失这份待补上下文，永久聊天原文仍保留。本版没有新建第二套记忆或修改宿主。
